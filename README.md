# 1on1話題ツール

1on1で「何を話せばいいか」困ったときの、個人向けの進め方シートです。

**使う:** https://shibatamago-dev.github.io/1on1-topic/

## どんなツールか

- 立場（上司／部下）、場面（定期／初回／評価前／忙しそう・困ってそう／キャリアの話がしたい）、時間（15分／30分）をチップで選ぶだけ
- 出てくるのは話題のリストではなく進め方1枚：最初の一言、メインテーマ（深掘り質問と、角の立たない聞き方の言い換え）、締めの一言
- 話したテーマの偏り（進捗／困りごと支援／成長・キャリア／チーム／コンディション／雑談）を端末内にだけ記録し、最近触れていない分類を次に勧めます
- 目安タイマー付き。配分に沿ってSTEPが進む縦バーで、厳密な管理ではなく目安として使います

## プライバシー

- 登録なし。名前も会話内容も入力しません（入力はチップの選択だけ）
- 偏りの記録は分類ごとの回数だけで、お使いのブラウザ内（localStorage）に保存され、サーバーには送信されません
- 記録はページ内のボタンからJSONで書き出し／読み込みができます

## 技術メモ

- 静的な1ページ（index.html のみ）。GitHub Pagesで配信
- アクセス集計に GoatCounter を使用（集計のみ、記録データは送信されません）
